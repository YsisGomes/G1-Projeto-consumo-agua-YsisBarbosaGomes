Sobre o projeto

Este projeto apresenta uma análise do consumo de água no Brasil, considerando informações relacionadas ao consumo, desperdício, níveis dos reservatórios, chuva, população e diferentes setores de consumo.

A análise busca identificar padrões temporais, diferenças entre regiões e estados, comportamento dos setores e possíveis relações entre fatores ambientais e o consumo de água.

Perguntas de análise

  • Quais estados apresentam maior consumo de água?
  • Quais regiões concentram os maiores volumes de consumo?
  • Quais setores apresentam maior consumo?
  • Existem padrões sazonais no consumo de água?
  • Qual é o nível médio de desperdício?
  • Como estão os níveis dos reservatórios?
  • Existe relação entre chuva e consumo de água?

Indicadores analisados

Consumo Total

Volume total de água consumido no período analisado.

UF com Maior Consumo

Estado que apresenta o maior volume de consumo.

Setor com Maior Consumo

Setor responsável pelo maior volume de consumo.

Consumo Per Capita

Média do consumo de água por habitante.

Desperdício Médio

Percentual médio de desperdício registrado.

Nível dos Reservatórios

Nível médio dos reservatórios no período analisado.

Dashboard interativo

O dashboard desenvolvido com Streamlit permite explorar os dados por meio de filtros de ano, mês, região, UF, setor de consumo e nível de alerta.

Os indicadores, gráficos e interpretações são atualizados dinamicamente de acordo com os filtros selecionados.

Objetivo acadêmico

O projeto foi desenvolvido com o objetivo de aplicar técnicas de análise, tratamento e visualização de dados utilizando Python, além da construção de uma aplicação interativa para apresentação dos resultados.

A análise possibilita compreender padrões relacionados ao consumo e ao desperdício de água, contribuindo para a interpretação dos dados e para a discussão sobre o uso eficiente dos recursos hídricos.
